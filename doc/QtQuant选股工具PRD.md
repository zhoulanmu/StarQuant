# Qt Quant 选股工具 PRD

| 项目 | 内容 |
|---|---|
| 版本 | V1.0 |
| 创建日期 | 2026-07-28 |
| 状态 | 已实现基础 V1 |
| 产品 | StarQuant Qt 桌面端 |

## 1. 背景

用户需要从 A 股股票池中按可重复的规则定位候选标的，而不是逐只浏览行情。本功能在桌面端提供“选择股票池 → 设置条件 → 执行筛选 → 查看命中依据 → 查看行情或加入自选”的完整闭环。

筛选结果仅用于信息检索和研究，不构成投资建议、收益承诺或交易指令。

## 2. V1 目标

1. 支持沪深北 A 股范围选择，并可排除 ST/*ST 与停牌证券。
2. 支持价格、涨跌幅、总市值、PE(TTM)、PB、换手率的区间组合筛选；条件间为 AND。
3. 提供趋势突破、低估值质量、活跃小中盘三个可修改的快捷模板。
4. 支持保存、加载、删除本地选股策略。
5. 结果明确展示每只股票的实时字段值、命中依据和数据截至时间，并可跳转现有行情页或加入自选。
6. 支持以用户输入的标的为目标，返回特征相近的候选股票及相似原因。

## 3. 用户流程

```text
选择股票池与基础过滤
  -> 勾选条件并填写区间，或应用快捷策略
  -> 运行选股
  -> 获取市场快照并按全部条件过滤
  -> 查看结果、命中依据和数据截至时间
  -> 查看行情 / 加入自选 / 保存策略
```

## 4. 功能需求

### 4.1 股票池与基础过滤

- 股票池：全 A 股、沪市主板、深市主板、创业板、科创板、北交所。
- 默认勾选“排除 ST/*ST”“排除停牌”。
- 停牌以最新价格不可用作为判断依据；ST 以证券简称包含 `ST` 作为判断依据。

### 4.2 条件编辑

用户可独立启用以下条件；每项填写最小值与最大值，最小值不得大于最大值：

| 条件 | 单位/口径 |
|---|---|
| 最新价 | 元，最新市场快照 |
| 涨跌幅 | %，最新市场快照 |
| 总市值 | 亿元，最新市场快照 |
| PE(TTM) | 数据源最新字段，可包含负值 |
| PB | 数据源最新字段 |
| 换手率 | %，最新市场快照 |

启用的所有条件均需满足。未启用任何条件时，仅按股票池和基础过滤返回结果。

### 4.3 快捷策略

| 模板 | 默认条件 |
|---|---|
| 趋势突破 | 涨跌幅 ≥ 2%，换手率 ≥ 3% |
| 低估值质量 | PE(TTM) 介于 0–20，PB ≤ 2 |
| 活跃小中盘 | 总市值 50–1000 亿元，换手率 ≥ 2% |

模板加载后可修改，且不会自动运行或覆盖已保存策略。

### 4.4 筛选结果与联动

- 结果默认按涨跌幅降序排列。
- 表格字段：代码、名称、最新价、涨跌幅、总市值、PE、PB、换手率、成交额、命中依据。
- 顶部展示股票池数量、命中数量及本次数据截至时间。
- 双击或点击“查看行情”跳转桌面端首页的现有行情页并切换到该股票。
- 点击“加入自选”复用现有自选持久化；重复操作不创建重复项。
- 无结果时保留条件并明确显示命中数为 0；数据源失败时保留已有结果和条件并允许重试。

### 4.5 相似标的

- 用户输入 6 位股票代码、带交易所后缀的代码或完整股票名称，例如 `600519`、`600519.SH`、`贵州茅台`。
- 首次查询时，客户端自动加载一份全市场快照；后续相似查询复用该快照，避免重复请求。
- 候选范围遵守当前股票池、排除 ST 和排除停牌设置，但不受普通数值筛选条件限制，避免预设区间掩盖真实相似标的。
- 相似度以总市值（35%）、PE（20%）、PB（15%）、换手率（15%）、成交额（10%）、当日涨跌幅（5%）计算。对市值、PE、PB、成交额使用对数距离，降低数量级差异造成的失真；字段缺失时从权重中剔除后重新归一化。
- 返回相似度最高的 30 只股票；结果列展示目标与候选的市值、估值、换手率对比，便于人工核验。

### 4.6 策略保存

- 用户输入名称后保存当前股票池、基础过滤与全部条件。
- 同名保存需确认覆盖。
- 支持加载和删除。
- 本地持久化使用 StarQuant 当前 `QSettings` 存储空间，按应用用户隔离。

## 5. 数据口径与依赖

V1 使用项目已采用的东方财富公开行情接口获取全市场列表，字段包括价格、涨跌幅、成交额、换手率、PE、PB 和总市值。页面必须显示本次请求的本地接收时间，而不将快照误标为逐笔实时数据。

网络、VPN 或公开接口限制可能造成请求失败；客户端应显示可读错误，不清空用户已设置的条件或上一次成功结果。

## 6. V1 边界与后续迭代

本次不提供自动交易、下单、收益预测、回测、定时任务或消息推送。MA/MACD/RSI、ROE、营收/净利润增长等需要完整日线和财务数据源，后续接入可信数据服务并统一口径后扩展；V1 不使用随机或模拟基本面数据参与选股。

## 7. 验收标准

1. 可按任一股票池和任意组合区间执行筛选，且返回结果全部满足已启用条件。
2. 条件上下界非法时禁止请求并提示错误。
3. 快捷策略可加载、修改、保存、重启应用后再加载。
4. 每条结果展示用于判断的实际字段值和命中依据。
5. 输入指定股票后可返回相似度降序的候选，且目标股票本身不得出现在结果内。
6. 结果可跳转行情并加入已有自选列表。
7. 接口失败或取消时，已编辑条件及上一次结果不丢失，界面可重试。
