# StarQuant 会员模式与桌面版改造方案

**日期：** 2026-07-28  
**审查范围：** `D:\QTquant` 的桌面端代码、现有产品文档与本地研究模式。  
**产品定位：** A 股研究与模拟交易工具；不具备已验证的商用数据授权、在线身份、订阅支付、券商交易或证券投资咨询资质。

## 一、结论：可以收费什么，不能先收费什么

### 建议收费的核心：研究工作流，而非“荐股”

| 可收费方向 | 用户付费价值 | 前提 |
| --- | --- | --- |
| 研究效率订阅 | 多工作区、更多保存策略、研究笔记、报告导出、跨设备同步、历史版本、筛选任务编排 | 账号、云存储、隐私、安全与售后能力 |
| 专业数据附加包 | 已授权的实时/延迟行情、历史数据、财务数据、公司行动、新闻数据和 SLA | 与数据商签订展示、缓存、计算、并发及再分发授权 |
| 团队席位 | 团队研究空间、共享策略、审批、审计、角色权限、SSO 和管理后台 | 企业账号、权限、审计、发票与客户成功流程 |
| 开放平台/API | 用户或企业自有授权数据的接入、批处理、导出和 API 用量 | API 鉴权、限流、计量、数据隔离和合同 |
| 投顾合作包（独立产品线） | 由持牌机构审核并提供的投顾服务 | 持牌合作、适当性、内容留痕、投诉处理和合规审查 |

### 不应作为普通会员权益售卖

- “每日金股”“VIP 股票池”“保证收益”“跟单”“买/卖点”“个性化仓位建议”。
- 用公开网络接口的数据包装成付费实时行情或数据转售。
- 以“相似标的”“策略信号”为名，实质提供收费个股推荐或投资建议。

证监会公开提示，未经批准以会员费、VIP 权限或“荐股软件”提供有偿证券分析、预测或建议存在非法证券投资咨询风险；软件工具提供投资建议也应纳入相应监管边界。正式定价和文案必须经过中国法律师及持牌合作方审查。参考：[证监会关于荐股软件的提示](https://www.csrc.gov.cn/csrc/c100028/c1002385/content.shtml)、[证券投资顾问业务暂行规定（现行有效）](https://neris.csrc.gov.cn/falvfagui/rdqsHeader/mainbody?navbarId=1&secFutrsLawId=3636153f028c44e9a00de8ed06494385)。

## 二、推荐会员结构

### 1. 本地研究版（免费）

目标是获取用户和验证研究流程，不承担在线服务承诺。

- 本地模拟账户、本地策略与有限数量的已保存筛选条件。
- 延迟/开发数据明确标注“仅研究用途”；无商用数据承诺。
- 无云同步、无实时推送、无团队协作、无 API。
- 不展示“免费荐股”“买卖建议”等用语。

### 2. 研究专业版（订阅）

收费对象是生产力功能，不以结果推荐作为权益。

- 无限研究工作区、策略版本、筛选模板和研究笔记。
- 历史快照比较、结果导出、研究报告生成、模拟复盘。
- 云同步、跨设备恢复、私有自选分组、用户自定义的条件提醒。
- 会员页写清：专业版不包含证券投资建议；数据权益依赖用户选择的授权数据包。

**建议计费：** 月付/年付的软件订阅；年付提供折扣，但不采用默认勾选的自动续费。自动续费前和续费日应显著提醒，并提供随时取消或变更入口。参考：[市场监管总局《网络交易监督管理办法》第十八条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2025/art_4b47c79b8d994a42bba4835997688faa.html)。

### 3. 数据专业包（附加订阅）

将数据成本和软件订阅拆开，按市场、频率、历史长度及并发数报价。

- 标准延迟行情包：仅在数据合同允许时提供。
- 实时行情包：单独授权、单独来源标识、单独服务等级。
- 基本面/事件/新闻包：按数据供应商许可范围开通。
- 页面显示“数据提供方、延迟状态、更新时间、许可范围”；任何数据不可用时降级为明确错误，不以缓存伪装实时。

### 4. 团队/企业版

按席位 + 数据用量 + 管理模块收费。

- 团队空间、共享研究、角色权限、操作审计、策略审批、私有数据连接器、SSO、专属支持。
- 企业数据必须逻辑隔离；导出、水印、审计日志和保留期限由合同约定。

## 三、会员页与购买路径

```text
本地研究版
  └─ 点击“升级研究工作区”
      ├─ 对比：研究效率权益（不展示“推荐股票”）
      ├─ 选择：月付 / 年付 / 数据附加包
      ├─ 价格、主体、发票、退款、自动续费、风险说明
      ├─ 登录或注册
      ├─ 支付与回调
      └─ 授权中心：当前方案、数据权限、到期日、取消续费、订单和发票
```

会员页必须避免“解锁优选股票”“会员专属涨停股”等结果导向文案。推荐主文案为“升级研究工作区”“提升研究组织、复盘与数据处理能力”。

## 四、桌面端现状（已核实）

| 已有能力 | 代码证据 | 价值 |
| --- | --- | --- |
| 本地研究模式 | `LoginDialog` 隐藏账号/密码，只允许进入本地研究模式 | 当前定位清晰，避免伪登录 |
| 风险、隐私和算法同意 | `LegalConsentDialog` 与三份资源文档，版本化同意存于 `QSettings` | 可作为研究内测的基础 |
| 条件选股与相似标的 | `StockScreener` 有分页、重试、筛选、相似度权重和命中依据 | 可形成研究工作流核心 |
| 本地保存 | 筛选策略、自选、账户等使用 `QSettings` | 支持单机体验，不支持会员服务 |
| 行情回退 | 行情模块使用多个公开来源回退 | 适合开发容错，不构成商用授权 |

| 缺失能力 | 影响 |
| --- | --- |
| 在线账户、身份、订阅、支付、订单、退款、发票、客服 | 无法向公众安全收费 |
| 授权行情适配层与合同证据 | 不能将当前公开接口作为付费数据服务 |
| 云同步、权益校验、设备管理、审计与监控 | 无法交付专业版/团队版承诺 |
| 会员权限模型 | 无法限制功能、数据包、席位与 API 用量 |
| 数据时间/来源/许可的产品化展示 | 用户无法判断研究结果的时效与边界 |

## 五、桌面版 P0/P1/P2 改造方案

### P0：收费与信任阻断项

| 项目 | 要改什么 | 验收标准 |
| --- | --- | --- |
| 商业边界开关 | 保留当前“本地研究模式”；所有会员、付费、数据包入口在未接入后台前显示“即将开放”，不得伪造购买流程。 | 当前版本没有任何在线支付、荐股或实盘入口。 |
| 账号与授权后端 | 新建独立服务：账号、会话、设备、会员方案、权益、订单、支付回调、退款、发票、注销和审计。桌面端仅保存短期会话令牌。 | 断网、过期、退款、换设备、取消续费均有确定的权益状态。 |
| 数据授权适配层 | 以供应商适配器替换直接公共接口；将数据授权、延迟、字段、缓存和来源信息作为元数据返回 UI。 | 每个报价、新闻和选股结果能显示来源、更新时间、延迟；无授权即不能在付费方案展示。 |
| 会员与投顾隔离 | 将“研究效率订阅”“数据附加包”“持牌投顾合作”建成不同产品/权限/文案/日志链路。 | 普通会员没有个股推荐、买卖建议或收益承诺。 |
| 消费者保障 | 完成价格页、用户协议、隐私政策、退款/发票、主体信息、客服投诉入口和自动续费提示。 | 下单前可见价格与关键条款；用户能取消续费、查询订单并申请退款。 |
| 安全与审计 | 密钥不进客户端；TLS、令牌刷新、最小权限、敏感数据加密、日志脱敏、异常告警、SBOM/签名与升级回滚。 | 安全评审、依赖清单、渗透/漏洞处置记录和发布审批齐备。 |

### P1：可售卖的研究体验

| 项目 | 要改什么 | 可承载的收费权益 |
| --- | --- | --- |
| 研究工作区 | 把本地 `QSettings` 策略、筛选、自选、模拟账户迁移为可同步的工作区，保留离线缓存和冲突提示。 | 多设备同步、更多工作区、版本历史 |
| 选股任务中心 | 筛选和相似标的显示数据时间、字段覆盖、算法版本、运行历史、失败原因与重试。 | 保存任务、定时运行、历史比较、导出 |
| 结果解释 | 相似度展示输入字段、权重、缺失字段和“仅研究”声明；不使用“推荐”“精选”等词。 | 高级解释报告、研究报告导出 |
| 数据包选择器 | 在行情/新闻/选股页面显示可用数据包与降级原因；用户只看到其已授权的字段。 | 延迟、实时、基本面、新闻等附加包 |
| 会员中心 | 方案、权益、数据包、到期时间、订单、发票、取消续费、设备与隐私设置。 | 订阅自助管理，降低客服成本 |
| 团队协作 | 共享只读/可编辑工作区、评论、审批、导出水印、角色和审计。 | 团队/企业席位 |

### P2：规模化与差异化

| 项目 | 要改什么 |
| --- | --- |
| 连接器与 API | 支持企业自带数据源、数据血缘、API 密钥、配额、计量和账单。 |
| 合规运营台 | 内容审核、算法/数据版本留痕、投诉工单、异常交易/使用监测与报表。 |
| 专业服务 | 企业部署、私有化、SSO、权限审计、专属数据集和 SLA。 |
| 持牌合作产品 | 仅在持牌机构参与并完成适当性、审查、留痕和投诉闭环后独立上线。 |

## 六、建议的实施顺序

1. **维持免费内测**：只提供本地研究与模拟交易；修复选股网络可靠性；完善数据来源、时间和“非商用数据”标识。
2. **P0 商业基础设施**：确定公司主体与数据供应商，完成法律审查；建设账号、权益、订单和支付沙箱。
3. **封闭付费试点**：仅销售研究工作区功能；数据包由已授权合同决定；测试退款、客服、权限、日志和故障降级。
4. **正式专业版**：完成发布闸门、监控、客服和发票流程后公开收费。
5. **团队/企业版与持牌合作版**：在个人订阅稳定后推进，不与普通会员混合销售。

## 七、商业化北极星与门槛指标

| 阶段 | 关键指标 |
| --- | --- |
| 内测 | 有效研究任务完成率、选股成功率、数据失败率、7 日留存、风险说明阅读完成率 |
| 付费试点 | 试用转付费、退款率、支持工单率、权益校验失败率、支付成功率 |
| 正式版 | 月活付费研究工作区、续费率、数据包毛利、净收入留存、严重合规/数据事故为零 |

## 八、发布决策

**当前结论：不可对公众收费。** 现有桌面端适合继续作为本地研究预览版；其法律同意和算法解释是良好起点，但公开数据接口、无在线账号支付和无权益/退款/审计能力仍是 P0 阻断项。
