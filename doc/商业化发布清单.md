# StarQuant 商业化发布清单

## 发布闸门：全部满足后才能对公众收费

| 闸门 | 必须证据 | 当前状态 |
|---|---|---|
| 产品边界 | 法务确认的研究工具定位；禁止性文案清单；风险揭示 | 待完成 |
| 投顾边界 | 不提供个股买卖建议、组合建议、个性化推荐或收益承诺；如提供则有持牌合作方案 | 待完成 |
| 数据授权 | 数据供应商合同，覆盖展示、缓存、计算、API 并发、再分发、来源标注和 SLA | 阻塞：当前为公开接口开发接入 |
| 主体与收费 | 公司主体、客服与投诉渠道、用户协议、隐私政策、价格/退款/发票规则 | 待完成 |
| 在线服务 | 真实认证、订阅授权、支付回调、风控、审计日志、账号注销与数据删除 | 待完成 |
| 隐私与安全 | 数据台账、留存策略、权限控制、加密、漏洞修复、事件响应、等级保护评估 | 待完成 |
| 算法治理 | 相似度/选股版本、输入字段、权重、结果留痕、人工复核、投诉入口 | 部分完成：界面已解释输入和结果 |
| 软件供应链 | SBOM、Qt/第三方许可审计、代码签名、升级回滚、发布审批 | 待完成 |
| 质量 | 自动化测试、行情异常测试、性能与容量测试、监控告警、灾备演练 | 待完成 |

## 当前可发布范围

仅可作为“本地研究与模拟交易预览版”使用：不收费、不使用真实账户、不接券商交易、不承诺收益，且不得把公开接口数据包装为商业行情服务。

## 建议上线顺序

1. **研究工具内测版**：完成本地风险提示、隐私说明、算法解释、开源声明和测试。
2. **受控试点版**：接入签约数据服务与真实账号订阅，限定测试用户，建立客服、日志、监控和退款流程。
3. **正式专业版**：通过法务/数据授权/安全/发布评审后收费发布。
4. **投顾合作版（可选）**：只在持牌证券投资咨询机构审核、内容留痕和适当性流程完成后上线。
